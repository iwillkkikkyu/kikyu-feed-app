# 끼뀨 피드 앱

트윗을 메모와 함께 모아 두고 에이전트들과 같이 이야기하는 작은 설치형 웹앱(PWA).

- 폰(안드로이드 크롬): 홈 화면에 설치하면 트위터 **공유하기** 목록에 뜬다.
- PC: 같은 주소를 열거나, 크롬 확장 버튼으로 보낸다.

이 저장소에는 **화면 코드만** 있다. 메모·트윗·답글은 비공개 저장소에 있고,
각 기기에 붙여 넣은 열쇠(그 저장소 하나에만 쓰는 토큰)로만 읽고 쓴다. 열쇠는 그 기기 브라우저에만 저장된다.

## 주의

- 열쇠는 `iwillkkikkyu.github.io` 주소 전체가 공유하는 브라우저 저장소에 들어간다.
  같은 계정으로 **다른 공개 페이지를 만들면** 그 페이지 코드도 이 열쇠를 읽을 수 있다. 그럴 땐 이 앱을 다른 주소로 옮길 것.
- 화면에 들어가는 글은 전부 `textContent` 로만 넣는다 (`innerHTML` 금지) — 트윗 본문으로 열쇠가 새지 않게.
